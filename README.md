# Ondina - Rama `feature/ventas`

Esta rama queda reservada para el módulo de **Ventas y Clientes**. Contiene
intencionalmente solo este README; la aplicación, la base de datos, la
configuración de OpenCode y las skills de trabajo se consultan desde `develop`.

## Alcance Del Módulo

- Registro de ventas y detalles con precio histórico.
- Gestión de clientes y cartera por vendedor.
- Medios de pago, documentos y gastos asociados.
- Comisiones relacionadas con ventas.

## Flujo De Trabajo

1. Actualiza tu rama desde `develop`.
2. Implementa una HU de ventas o clientes sin duplicar la aplicación ni crear
   carpetas permanentes por módulo.
3. Coordina con `feature/bodega` cuando el cambio afecte carga o stock.
4. Agrega pruebas y abre un Pull Request hacia `develop`.

Consulta el README de `develop` para la instalación inicial de Ubuntu, React,
Vite, Supabase, OpenCode, CodeGraph, Beads, Mem0 y MCPs.
