# Ondina - Rama `feature/administracion`

Esta rama queda reservada para el módulo de **Administración**. Contiene
intencionalmente solo este README; la aplicación, la base de datos, la
configuración de OpenCode y las skills de trabajo se consultan desde `develop`.

## Alcance Del Módulo

- Gestión de usuarios, perfiles, roles y sucursales.
- Catálogo y configuración operativa.
- Comisiones, reportes y auditoría.
- Alertas de clientes inactivos y ubicaciones GPS.

## Flujo De Trabajo

1. Actualiza tu rama desde `develop`.
2. Implementa una HU administrativa sin duplicar la aplicación ni crear carpetas
   permanentes por módulo.
3. Coordina con los demás dominios cualquier cambio de permisos, catálogo o
   contrato compartido.
4. Agrega pruebas y abre un Pull Request hacia `develop`.

Consulta el README de `develop` para la instalación inicial de Ubuntu, React,
Vite, Supabase, OpenCode, CodeGraph, Beads, Mem0 y MCPs.
