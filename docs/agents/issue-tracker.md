# Seguimiento de trabajo

Beads es el tracker duradero de Ondina: IDs OND, dependencia nativa con bd dep add, aceptación y evidencia en el issue. Ejecutar bd prime al recuperar contexto.
GitHub contiene issues para revisión y asignación humana; mantener su URL en external_ref. Publicar o modificar GitHub cuando la solicitud lo autorice.
No usar .scratch/issues ni Markdown como otro tracker. Un plan es una especificación; su estado de ejecución pertenece a Beads.
Los Run, Task y Dispatch de Orca son registros de ejecución supervisada. Referenciar el issue de Beads en la spec y mantener sus asociaciones; cerrar Beads solo cuando se valide el resultado.
