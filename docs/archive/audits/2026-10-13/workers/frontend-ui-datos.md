### FUI-N1 — Variantes de URL evaden la comprobación de roles de interfaz

- **Severidad:** alta. **Estado:** confirmado (código y ejecución local de matching; sin navegación autenticada ni prueba de RLS).
- **Evidencia:** `frontend/src/components/DashboardLayout.tsx:31-33` busca igualdad literal; `frontend/src/App.tsx:12-18` no pasa roles; `frontend/src/types/module.ts:12-15` no los declara en rutas. `/stock` se reserva a bodega/admin en `frontend/src/domains/bodega/index.tsx:22`; todas las rutas funcionales actuales están en nav, pero el matching no comparte la normalización del router.
- **Comando usado:** el siguiente programa de solo lectura invoca el router instalado, sin ejecutar suite ni build:

```sh
node --input-type=module - <<'JS'
import { matchRoutes } from './frontend/node_modules/react-router/dist/development/index.mjs';
const routes = [{path:'/stock'},{path:'/produccion/registrar'},{path:'/administracion'}];
for (const pathname of ['/stock','/stock/','/STOCK','/administracion/','/PRODUCCION/registrar']) {
  console.log(JSON.stringify({pathname,
    matched:matchRoutes(routes,pathname)?.map(x=>x.route.path),
    exactNav:routes.find(x=>x.path===pathname)?.path??null}));
}
JS
```

- **Resultado:** `/stock` matched `/stock` y exactNav `/stock`; `/stock/` y `/STOCK` matched `/stock` y exactNav `null`; `/administracion/` matched `/administracion` y exactNav `null`; `/PRODUCCION/registrar` matched `/produccion/registrar` y exactNav `null`.
- **Impacto:** un vendedor autenticado puede alcanzar componentes de otro rol mediante esas variantes. En producción una ruta con sección mayúscula puede además no seleccionar sección por `pathname.split('/').at(-1)` (`Produccion.tsx:27`). Las peticiones resultantes siguen sujetas a RLS/RPC: no se afirma lectura/escritura remota no autorizada.
- **Issue relacionado:** #36 / OND-82e ya exige rutas directas/alias fuera del menú, pero no enumera este caso reproducido. Añadir ejemplos y criterio: matriz rol × ruta con barra final, mayúsculas, alias y ruta canónica produce la misma autorización; permisos asociados al matching de Route, independientes del menú. Probar también `/produccion` que redirige a ruta protegida; no clasificar ese alias como bypass de pantalla por sí solo.
