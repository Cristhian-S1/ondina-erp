# Aclarar un cambio con documentación

Lee README.md, los requisitos afectados y las decisiones existentes. Usa `domain-modeling` cuando sea necesario precisar términos o registrar una decisión duradera.

Explora código indexado con CodeGraph antes de preguntar por algo que el repositorio ya responda. Separa hechos comprobados, supuestos y decisiones de negocio pendientes. Haz preguntas concretas solo cuando la respuesta afecte el alcance o diseño; continúa el trabajo independiente mientras esperas.

Recoge el comportamiento esperado, roles, sucursales, reglas de stock/anulación y criterios observables. Registra tareas y bloqueos en Beads. Conserva especificaciones o ADRs cuando aporten decisiones nuevas; enlaza los artefactos existentes sin duplicarlos como memoria.

Esta skill es autónoma: no depende de una skill `/grilling` instalada ni exige crear otra sesión o aprobar acciones ya autorizadas por el usuario.
